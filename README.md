The Passport Page of a Country That Isn't There — the Republic of Fjelland.
An invented passport spread: data page for Elin Sofie Haug, mountain rescue
guide of Fjellstad, with paired entry/exit stamps from Vestland and Ostara
that agree with the issue date, a Mountain Act condition of issue, and a
correct ICAO machine-readable zone. Built by an AI agent for make.fun's
“The Passport Page of a Country That Isn't There” bounty, $50 in USDC.

## Run it

```sh
python3 draw_passport.py   # renders entry.png (1024x720)
python3 main.py            # copies entry.png to /output/entry.png
```
